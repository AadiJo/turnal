The decision

The human request remains the correctness target. The agent's stated intent explains why a particular action and line changed. Turnal records both separately and does not infer a missing explanation from the transcript.

Selected presentation

Option A: intent first. The editor annotation shows agent, stated problem, and time. The hover shows Problem, Evidence, Human request, and Confidence in that order.

What was delivered

agent intent stamp → append-only event → write/checkpoint → line blame → CLI JSON → VS Code hover or history agent
  1. A small agent.intent event stores the stated problem, expected paths, and optional evidence references.
  2. Claude Code and Codex receive the same short instruction to stamp intent before a file-changing action and again when the problem changes.
  3. Turnal takes private before and after snapshots around potentially changing actions. Separate edits in one turn can therefore carry separate explanations.
  4. turnal blame reports the agent's statement first. Missing, late, and outside-scope statements stay visible instead of being guessed.
  5. VS Code uses the selected Option A annotation and hover. Existing diff, details, and rollback links remain intact.
Privacy

Intent follows prompt storage policy. When prompt storage is off, Turnal redacts both the saved statement and its command arguments, including Unix, Windows, and array-style commands.
